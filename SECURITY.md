⚠️ **This repository contains a deliberately vulnerable application.**

It is intended **only** for local use while testing the [ICARUS Burp Suite extension](https://github.com/IcarusSec/ICARUS).

- Do **not** deploy this on any public server or shared network.
- Do **not** use real credentials, tokens, or PII in requests against this lab.
- All vulnerabilities are intentional teaching tools, not bugs to report.

If you find an unintentional vulnerability in the *lab infrastructure itself* (e.g., a way to escape the Flask process, Docker breakout, etc.), feel free to open a private issue.
